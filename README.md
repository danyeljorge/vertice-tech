# Danter

Plataforma institucional e portal da Danter — Engenharia de Software, Cloud Architecture e Agentes Autônomos de Inteligência Artificial.

## Stack & Design Engineering
- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS
- **Micro-interactions & Physics**: Framer Motion seguindo os princípios de design engineering de [emilkowalski/skills](https://github.com/emilkowalski/skills)
- **Icons**: Lucide React
